# AI-buddy — быстрый старт Codex на Mac

Архив содержит исходные документы без изменения, конфигурацию агентов, правила, этапы, CI и команду проверки. Это конфигурация разработки, НЕ готовое приложение. Распакуй в корень уже клонированного репозитория (не заменяй существующие изменения без проверки). Скрытая папка .codex тоже должна быть скопирована. CI до завершения каркаса будет красным — это ожидаемо.

1. Установи/обнови CLI `npm install -g @openai/codex@latest` (нужен Node.js) и запусти Docker Desktop. `codex --version`, `docker compose version`, `docker info`, `codex login` (ChatGPT account).
2. Перейди в репозиторий, `git switch -c feat/ai-buddy`, проверь `git status`. Зафиксируй только файлы этого архива после просмотра (`git add AGENTS.md CLAUDE.md tech.md LEAD.md DEV_A.md DEV_B.md original-tz.txt START.md README-CODEX.md .codex docs scripts/check.sh .github/workflows/quality.yml` и `git commit -m "chore: configure codex pipeline"`). На пустом репо без коммитов сначала создай начальный коммит.
3. `caffeinate -i codex` (не дает Mac уснуть на время работы процесса). Доверь проект, если CLI спросит, и отправь: `/goal Реализуй AI-buddy по START.md и AGENTS.md. Пройди все этапы docs/PLAN.md с независимыми субагентами, реальными проверками scripts/check.sh, локальными коммитами и отчётом docs/PROGRESS.md. Не завершай цель до проверенного оффлайн-демо либо задокументированного блокера.` В разрешениях используй workspace-write + on-request; подтверждай только ожидаемые установки, Docker и локальные git-команды. Не включай unrestricted/full access на личном Mac. В отдельных версиях интерфейс настроек и команды могут отличаться.
4. Если лимит закончился или сессия оборвалась: `codex resume --last`, затем `/goal resume` (если цель приостановлена), либо новая сессия, затем `Прочитай docs/PROGRESS.md и текущий git status. Продолжи с первого непроверенного этапа, не сбрасывай изменения.` Если /goal недоступна, обнови CLI; обычный промпт из START.md тоже работает, но может потребовать команду «продолжай». Не запускать два lead одновременно в одной рабочей копии.
5. После стабилизации `bash scripts/check.sh` с пустым LLM_API_KEY и запуск стенда из README приложения. Проверь UI вручную: http://localhost:3000. `git status`, `git log --oneline`, просмотри diff; потом `git push -u origin feat/ai-buddy` и создай PR. В GitHub Settings -> Rules/Branches настрой обязательный quality-gate (если тариф репозитория поддерживает), не включай автоматический merge без проверки демо. CI не требует ключа OpenAI.

Режим без интерактивных подтверждений: `codex exec --sandbox workspace-write "Read START.md and execute it; if Docker is blocked, record the commands and stop only the affected step."` использует сохраненную авторизацию CLI, но sandbox может блокировать Docker. Интерактивный запуск предпочтительнее на личном Mac. Не обещает автоматического возобновления после исчерпания квоты; возобнови вручную. GitHub Actions запускает реальные проверки, а не расходует AI-квоту. Если надо E2E вне Compose, сначала согласуй изменение команды с лидом, не исключай тесты из gate.

Демо не предназначено для публичной эксплуатации: фиксированный код и роли, заглушки корпоративных сервисов и синтетические данные. Настоящий Telegram запуск требует бота/HTTPS и проверки initData отдельно. Секреты не добавлять в репозиторий.
